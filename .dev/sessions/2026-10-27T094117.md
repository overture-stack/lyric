Added a download of every file's error report in one zip, completing the errors-by-file work so a user can fetch all reports of a Submission at once instead of one file at a time.

- `packages/data-provider/src/controllers/submissionController.ts`, `src/routers/submissionRouter.ts`, `src/utils/schemas.ts`: `GET /submission/:submissionId/errors/download/all` with an optional `fileType` (`csv` or `tsv`, defaulting to `csv`, like the single file download); responds with `submission_{submissionId}_all_errors.zip`
- `packages/data-provider/src/services/submission/submissionService.ts`, `src/repository/submissionRecordsRepository.ts`, `src/utils/submissionTypes.ts`: `getSubmissionErrorReportsBySubmissionId` groups the errors of the whole Submission by file from a single query; files without errors are omitted, and a missing Submission or one without any error answers 404
- `packages/data-provider/src/utils/fileUtils.ts`: `getErrorReportFileName` is shared by the single file download and the zip entries, so a report has the same name in both
- `apps/server/swagger/submission-api.yml`: documented the endpoint
- `.dev/tech-debt.md`: resolved the "zip for all files in a submission" entry
- Tests: unit coverage for the report file name; integration coverage that opens the downloaded zip and checks entry names and contents for TSV and CSV, same-entity files getting distinct names, a clean file being left out, an unsupported `fileType`, a missing Submission, and a Submission without errors
